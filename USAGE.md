# ZoneMax — руководство пользователя

ZoneMax превращает каждый монитор в одну или две логические области и позволяет максимально развернуть окно именно в выбранной области. Окно остаётся настоящим maximized-окном Windows: у него сохраняется штатное состояние максимизации и нет обычной рамки изменения размера у верхнего края зоны.

## Быстрый старт

1. Запустите `ZoneMax.exe`. Программа сворачивается в системный трей и по умолчанию добавляет себя в автозапуск текущего пользователя Windows.
2. На основном мониторе нажмите `Win+Left` или `Win+Right`. ZoneMax включит для этого монитора режим двух зон и поместит активное окно в левую или правую зону.
3. Нажмите штатную кнопку максимизации окна или дважды щёлкните по заголовку: окно развернётся в своей текущей зоне.
4. Чтобы выбрать другое соотношение, откройте контекстное меню значка ZoneMax в трее → **Split ratio** и выберите нужную пару процентов.

Режим монитора сохраняется по имени устройства. По умолчанию основной монитор разделён на две зоны, а остальные мониторы работают как обычные полноэкранные области, пока вы не включите для них split сочетанием `Win+Left` или `Win+Right`.

## Горячие клавиши

Сочетания с `Win` перехватываются ZoneMax для обычных окон, которыми процесс может управлять. Для повышенных (elevated) окон команда передаётся стандартному Windows Snap. ZoneMax обрабатывает стрелки с `Win`, когда одновременно не нажаты `Ctrl` или `Alt`. Сочетания с `Win+Arrow` можно отключить в tray-меню или через `snapkeys`.

| Сочетание | Действие |
|---|---|
| `Win+Left` | Включить split для монитора активного окна и максимально развернуть окно в левой зоне. Если окно уже занимает эту зону, перейти на предыдущий монитор и занять его крайнюю правую зону. |
| `Win+Right` | Включить split и максимально развернуть окно в правой зоне. Если окно уже занимает эту зону, перейти на следующий монитор и занять его крайнюю левую зону. |
| `Win+Up` | Переключить монитор активного окна в режим одной зоны и развернуть окно на всю рабочую область монитора. |
| `Win+Down` | Если окно развернуто — восстановить его. Иначе свернуть окно. |
| `Win+Shift+Left` | Переместить окно на предыдущий монитор, в его крайнюю правую зону. |
| `Win+Shift+Right` | Переместить окно на следующий монитор, в его крайнюю левую зону. |

Порядок мониторов для команд перехода определяется сортировкой по координатам слева направо, затем сверху вниз. Команды `Win+Shift+Left/Right` циклически переходят через край списка. Если мониторов меньше двух, перемещать окно некуда.

`Win+Left/Right` на уже занятой крайней зоне продолжает переход только при наличии следующего монитора в соответствующем направлении; на краю рабочего стола команда ничего не меняет. `Win+Shift+Up/Down` ZoneMax не использует.

## Мышь и кнопки окна

- **Кнопка максимизации окна** и **двойной щелчок по заголовку** максимально разворачивают окно в зоне, где оно находится.
- **`Shift` + кнопка максимизации** оставляет ZoneMax вне операции: Windows разворачивает окно на весь монитор. Удерживайте `Shift` и при отпускании окна после перетаскивания, чтобы оставить его в точном месте.
- При включённой настройке **Drag to a screen edge to fill a zone** перетащите окно к внешнему краю рабочего стола и отпустите его в пределах примерно 18 пикселей от края:
  - верхний край выбирает зону под точкой отпускания;
  - левый край выбирает левую зону;
  - правый край выбирает правую зону.
- Перетаскивание через границу между мониторами не считается внешним краем. Нижний край не является жестом размещения зоны.
- Обычное перемещение окна без отпускания у внешнего края только обновляет его принадлежность к зоне.

## Режимы и геометрия зон

У каждого монитора есть режим:

- **Single** — одна зона размером с рабочую область монитора. `Win+Up` включает этот режим.
- **Split** — две вертикальные зоны. `Win+Left/Right` включает этот режим.

Доля левой зоны задаётся `splitfraction`. Правая зона получает оставшуюся ширину. Например, `0.95` означает 95% слева и 5% справа; `0.05` — 5% слева и 95% справа. Допустимы значения от `0.05` до `0.95` включительно. Границы зон смежны: ширина правой зоны рассчитывается как остаток рабочей ширины монитора.

На мониторе с рабочей шириной меньше 700 пикселей ZoneMax использует одну полноразмерную зону, даже если для него выбран Split. Это ограничение предотвращает создание двух практически непригодных областей на узком экране.

Соотношение применяется к рабочей области каждого монитора отдельно. Оно не вычисляется по ширине основного дисплея для остальных мониторов. В меню размеры в пикселях показаны для основного монитора; доля применяется к ширине соответствующего монитора.

## Значок в системном трее

Нажмите правой кнопкой мыши на значке ZoneMax. Меню содержит:

| Пункт меню | Назначение |
|---|---|
| **Split ratio** | Выбрать долю левой и правой зон. Выбранное значение записывается в `zonemax.ini`; после выбора на 2 секунды показывается полупрозрачное расположение зон на мониторах. |
| **Win+Arrow drives the zones** | Включить или отключить обработку `Win+Arrow`. При выключении эти сочетания остаются Windows. |
| **Drag to a screen edge to fill a zone** | Включить или отключить размещение перетаскиванием к внешним краям экрана. |
| **Seamless maximize (no flicker)** | Управлять временной установкой рабочей области перед максимизацией. Отключение может убрать этот способ бесшовного максимизирования. |
| **Keep windows inside their zone** | Включить или отключить автоматическое исправление некоторых непреднамеренных выходов maximized-окна из его зоны. |
| **Log every action (debug)** | Включить подробную запись действий, размещения окон и диагностики в файл журнала. |
| **Start with Windows** | Включить или отключить запуск через раздел автозапуска текущего пользователя Windows. |
| **Edit config...** | Открыть `zonemax.ini` в Блокноте. |
| **Reload config** | Повторно прочитать файл, обновить зоны и настройки, перечитать режимы мониторов и обновить tray-меню без перезапуска приложения. |
| **Reset work area (panic button)** | Снять временно установленную рабочую область и заново определить настоящие рабочие области мониторов. |
| **Open log** | Открыть `zonemax.log` в Блокноте. |
| **Exit ZoneMax** | Завершить приложение и восстановить рабочие области Windows. |

В **Split ratio** доступны значения `50 / 50`, `60 / 40`, `70 / 30`, `80 / 20`, `90 / 10`, `95 / 5`, `40 / 60`, `30 / 70`, `20 / 80`, `10 / 90` и `5 / 95`. Первый процент всегда относится к левой зоне.

Отдельного сочетания клавиш для показа preview в текущей версии нет: preview отображается после выбора ratio из меню.

## Файл конфигурации

`zonemax.ini` находится рядом с `ZoneMax.exe`. При первом запуске файл создаётся автоматически. После чтения конфигурации приложение сохраняет её в нормализованном виде. Строки, начинающиеся с `;` или `#`, считаются комментариями.

Пример:

```ini
[options]
autofix = true
seamless = true
snapkeys = true
dragzones = true
verbose = true
startup = true
splitfraction = 0.95

[modes]
\\.\DISPLAY1 = split
\\.\DISPLAY2 = single
```

Числа в файле используют точку и invariant-формат независимо от региональных настроек Windows. Например, записывайте `0.95`, а не `0,95`.

### Параметры `[options]`

| Ключ | По умолчанию | Значения | Описание |
|---|---:|---|---|
| `autofix` | `true` | `true` / `false` | Исправлять два распознаваемых ошибочных состояния maximized-окна: разворот на весь монитор вместо запомненной зоны или разворот в другую зону. Намеренное обычное изменение размера не исправляется. |
| `seamless` | `true` | `true` / `false` | Перед кликом по максимизации кратковременно установить рабочую область монитора равной зоне, чтобы Windows выполнила настоящее максимизирование внутри неё. |
| `snapkeys` | `true` | `true` / `false` | Передавать ZoneMax сочетания `Win+Arrow`. При `false` их обрабатывает Windows. |
| `dragzones` | `true` | `true` / `false` | Включить жест размещения окна отпусканием у внешнего края монитора. |
| `verbose` | `true` | `true` / `false` | Записывать подробные события в журнал. Основные сообщения о запуске, ошибках и конфигурации записываются независимо от этого параметра. |
| `startup` | `true` | `true` / `false` | Синхронизировать автозапуск ZoneMax с этим значением для текущего пользователя Windows. |
| `splitfraction` | `0.5` | `0.05`–`0.95` включительно | Доля ширины левой зоны. Например, `0.9` даёт 90/10, а `0.05` — 5/95. |

Для булевых параметров распознаются `true` и `1` как включённые; прочее значение читается как `false`. Для `splitfraction` пустое, нечисловое или выходящее за диапазон значение отклоняется и заменяется предыдущим валидным значением в файле, либо значением по умолчанию `0.5`. Ошибка записывается в журнал. При `Reload config` нормализованная конфигурация сохраняется обратно в файл.

### Параметры `[modes]`

В этой секции ключ — имя устройства монитора, например `\\.\DISPLAY1`, а значение — `split` или `single`. Режимы сохраняются по имени дисплея и не зависят от того, какие координаты или разрешение были у монитора при сохранении. Неизвестное значение режима читается как `single`.

Если для дисплея нет записи, действует начальное правило: основной монитор — `split`, остальные — `single`. Горячие клавиши изменяют режим текущего монитора и сразу сохраняют его в конфигурацию.

## Типичные варианты использования

### Большая основная зона и узкая боковая

В tray-меню выберите **Split ratio → 90 / 10** или **95 / 5**. Затем нажмите `Win+Left`, чтобы отправить активное окно в большую левую зону, или `Win+Right`, чтобы отправить его в узкую правую зону. Для обратного расположения выберите `10 / 90` или `5 / 95`. Можно также перетащить окно к верхнему краю и отпустить его над нужной зоной. Когда окно уже находится в правильной зоне, обычная кнопка максимизации развернёт его в ней.

### Вернуться к обычному максимизированию

Нажмите `Win+Up`: монитор переключится в Single, а активное окно развернётся на всю рабочую область. Выбранный `splitfraction` останется сохранён и снова будет применён при следующем `Win+Left/Right`.

### Переместить окно на другой монитор

Используйте `Win+Shift+Left/Right`. Окно попадёт в зону у стороны прибытия. Либо перетащите его через границу мониторов и отпустите у внешнего края целевого монитора, если нужен выбор зоны по краю.

### Изменить конфигурацию вручную

Откройте tray-меню → **Edit config...**, измените нужные строки и сохраните файл. Затем выберите **Reload config**. Для изменения только доли проще использовать **Split ratio**.

## Журнал и восстановление

`zonemax.log` создаётся рядом с исполняемым файлом. Большой журнал периодически переносится в `zonemax.log.old`. Включите **Log every action (debug)**, если нужно отследить назначения зон, горячие клавиши, временное переключение рабочей области или автоматическое исправление окна.

Если рабочая область Windows выглядит неправильной, используйте **Reset work area (panic button)**. При обычном выходе ZoneMax снимает временное изменение рабочей области и возвращает рассчитанную область Windows с учётом панели задач. Не завершайте процесс принудительно в момент, когда окно максимизируется в зоне.

## Особенности и ограничения

- ZoneMax ориентирован на разделение одного монитора на две вертикальные зоны, а не на произвольную сетку окон.
- Для работы требуются Windows 10 версии 1703 или новее либо Windows 11 и встроенный .NET Framework 4.x.
- Окна, запущенные с повышенными правами, не управляются ZoneMax из обычного процесса. Их `Win+Arrow` передаётся Windows.
- Для перетаскивания maximized-окон должна быть включена функция привязки окон Windows. ZoneMax обеспечивает её включённое состояние, потому что Windows использует эту функцию для перетаскивания максимизированного окна за заголовок.
- Временное изменение рабочей области — системная техника, благодаря которой окно получает настоящее состояние максимизации внутри зоны. Она не превращает ZoneMax в постоянную замену обычной системной рабочей области.

## Сборка из исходного кода

Для сборки из PowerShell выполните:

```powershell
.\build.ps1
```

Скрипт компилирует `ZoneMax.cs` штатным `csc.exe` из .NET Framework и создаёт `ZoneMax.exe` рядом с исходниками. Перед компиляцией он останавливает запущенный процесс ZoneMax.
